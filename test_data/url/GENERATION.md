# P1A data generation

P1A stores approved fixtures verbatim and records hashes. The locked `url 2.5.7` oracle dataset is generated by an external temporary black-box harness and is not a product implementation.

P2 generates private passive IDNA tables with `tools/url-data/generate_idna_tables.py`. The generator reads only the committed Unicode 17.0.0 IDNA mapping, joining-type, bidi-class, and general-category inputs, verifies the approved mapping-input hash and version, and reproduces `src/values/uri/url/engine/idna/tables.rs` byte-for-byte. The WPT and Unicode vector generators only turn approved fixture data into private Rust test vectors; they do not implement URL behavior or access the network.
